## Relationship to the rewrite

The broader rewrite series currently covers Books 0–24 across Volumes I–V, with Volume 0 (Books 20–22) maintained as a separate witness track. The source snapshots in this directory cover only the four volumes listed above; they are **not** a complete source archive for every book in the rewrite.

The rewrite and its supporting research materials are a separate commentary layer. Nothing in this directory is changed by edits to the rewrite pages. Status tags inside the manuscripts (CERTIFIED, etc.) are the manuscripts' own labels, not independent re-verification.
