# Original manuscripts (read-only reference)

This directory contains reference copies of selected source manuscripts used by the rewrite series. The files are preserved as source snapshots; they are not edited as part of the rewrite.

- R-Theory-Volume-I-original.txt — Volume I (Books 0–6). Retrieved from the read-only Google Doc 2026-09-18; revision id is recorded in the file header.
- R-Theory-Volume-II-original.txt — Volume II (Books 7–13). Drive export 2026-09-19; ends with "END OF VOLUME II".
- R-Theory-Volume-III-original.txt — Volume III (Books 14–16). From the Volume III audit working copy.
- R-Theory-Volume-IV-original.txt — Volume IV (Books 17–19). Extracted 2026-09-30 from the author's R_Theory_volume_IV.docx; provenance details are recorded in the source history.

## Coverage boundary

The snapshots listed above document source material for Volumes I–IV (Books 0–19). They do not constitute a complete source archive for Books 20–24 or Volume 0 / Volume V. The absence of a snapshot here does not imply that later books have no source material elsewhere; it means this directory does not currently document equivalent original-manuscript snapshots for them.

The rewrite series currently extends through Books 0–24. Volume 0 (Books 20–22) is a separate witness track, not a chronological continuation of Volumes I–IV; Volume V contains Books 23–24.

Status tags inside source manuscripts (for example, CERTIFIED) are the manuscripts' own labels, not independent re-verification. Nothing in this directory changes or upgrades those labels.
